历史卡片 · 设计稿 v3

黑白灰 + Azure-600 主题色 · 八类内容示例

① 先确认：卡片显示哪些数据

kind    text|url|rich|code|html|math|image|file   ← 决定预览怎么渲染
text    纯文本预览 —— 搜索命中字段，任何类型都有
lang    代码语言 → 等宽 + 语法着色 + 右上角语言标签
html    rich / html 的渲染片段
tex     公式的 LaTeX 源码（hover 卡片查看）
image   { w, h } → 缩略图 + 「1920 × 1080」
──────── 元信息：决定「要不要用它」 ────────
time    今天 22:29 / 昨天 18:02 / 09-30 19:46 / 跨年带年份
chars   字符数（图片无）：1,234 字符 / 1.2万 字符
bytes   48 B / 74.8 KB / 2.4 MB
source  { 图标, 名称 } 来源应用，超长省略 + title
  • 选中 / 焦点是 UI 交互状态，不落库。

② 八类卡片的预览策略

类型预览
文本 text3 行截断，保留换行
链接 url主题色下划线、断行 2 行；筛选归入「文本」
富文本 rich原样渲染：加粗 / 斜体 / 强调色 / 列表
代码 code深色块 + 语法着色 + 语言标签，3 行截断
网页 html迷你浏览器框，「渲染 / 源码」切换；筛选归入「代码」
公式 mathCSS 排版渲染（分数/根号/上标），hover 看 LaTeX
图片 image56px 缩略图 + 尺寸 + 格式
文件 file文件名 + 「等 N 个文件」

③ v3 布局与视觉优化

  • 结构：导航 → 搜索（带图标、focus 光环）→ 统计行 → 筛选（可横滚）→ 列表。
  • 列表浅灰底（neutral-50）衬托白卡；留白分隔，不用分割线。
  • 悬停：边框加深 + 轻投影；右上浮现「复制」按钮，单击即复制、不改变选中。
  • 选中：azure-50 底 + azure-200 边 + 左侧 3px 竖条；「删除所选」hover 转红。
  • 代码块 neutral-900 深底与白色卡片形成深浅对比，代码一眼可辨。
  • 元信息行：类型 · 时间 · 字符数 · 体积 ｜ 来源应用。

④ 交互与快捷键

  • ↑ ↓ 移动选中（自动滚入视野）；Enter 复制；Space 多选切换
  • Ctrl 点击加选、Shift 范围选、Ctrl+A 全选、Ctrl+F 搜索
  • Delete 删除已选；Esc 清空选中 / 清空搜索；双击卡片 = 复制

⑤ 仍不做

  • 序号徽标；固定/收藏、标签（模型暂无字段）。
  • 真实 HTML 渲染需 sandbox iframe + 样式白名单；本稿为受控静态片段。
  • 代码着色为手写 span 示意，实现期可接 highlight.js。
