Primitive 原始色阶

色阶可用于生成语义颜色，但业务组件不得直接引用。浅色主题显示 B 档，深色主题显示 A 档；扩展色按统一明度阶梯生成，按分组阅读即可。点击任意色块可复制 Hex。

Semantic roles

Component Token 矩阵

保留最小视觉契约，完整交互由具体项目和 Reka UI 原语实现。基础组件（原子）：Box、Button、Input、Textarea、Checkbox、Radio、Switch、Tag、Link、Text、Icon、Divider、Progress、Spinner、Avatar。Box 是最底层的盒子，Panel、Popover、Dialog、Tooltip、Toast 是它的预设。其余（Select、Menu、Tabs、List、Table、Dialog……）是组合，直接复用原子的变量。这里用于检查组件 Token 在不同状态和主题下的映射。状态色统一规则：悬停 = 组件自身文字色以 8% 叠加在自身背景上，按下 = 10%；深浅主题自动反向，新增变体无需再逐个挑色。

浮层 Token 矩阵

仅保留浮层的视觉层级和状态预览。Dialog、Menu、Popover、Tooltip、Toast 的键盘和焦点行为由 Reka UI 提供。层级约定：popover、tooltip 高于 dialog，保证 Dialog 内可以打开 Select / Popover；Dialog 打开时对页面其余浮层的压制由 Reka UI 的 Portal 与遮罩负责，不依赖全局 z-index。
