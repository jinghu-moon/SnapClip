信息层级

默认卡片只承载扫描所需信息，其余下沉到 Hover / 菜单 / 详情
第一层
复制内容（预览，最多 2 行）— 唯一高视觉优先级。长内容截断 + 省略号，卡片高度固定节奏，滚动时靠内容本身区分记录。
第二层
来源 · 时间（同一行）— 应用图标 + 名称 + 相对时间。尺寸/字数不进默认层（Hover 或详情再看）。
第三层
状态 — 仅「固定」常驻（左侧色条 + 标签）。标签、重复等不默认展示。
第四层
操作 — Hover / 键盘聚焦后出现。高频直出，低频进 ···，破坏性弱化且不直出。

对比结论

维度方案 A · 点击复制方案 B · 点击选中
操作效率最高（1 次点击）多一步（定位按钮或快捷键）
可发现性依赖习惯 / 提示（首次需告知）按钮显式，无需学习
视觉简洁度Hover 只留 ···多一个主按钮
高频体验连续粘贴/复用时极快稳定，略慢
误操作点击即覆盖剪切板（可撤销/历史可找回）几乎无误触复制
扩展性选中语义弱，批量/详情需另设计天然支持详情面板、多选
推荐：默认方案 A，方案 B 作为「专注模式」可切换。 剪切板管理器的核心动作就是「放回剪切板」，A 的效率优势在全天高频使用中非常明显。 误覆盖可通过历史回溯缓解；若产品要承载详情/批量/预览，再启用 B 或双击预览。 Demo 默认 A，顶部可切换，两种都可在完整列表中实操。

固定 vs 收藏

两者语义高度重复。剪切板场景真正需要的是「不被清理、置顶」——这是「固定」。 「收藏」若只是筛选入口，会增加卡片上第二个星标，扫视成本上升。

结论：卡片只保留「固定」。 不引入独立收藏。若未来要「知识库式收藏」，放到详情或标签体系，而不是列表卡片第二颗星。

布局与交互规则

桌面端长期高频使用

布局

卡片高度固定节奏（约 88–100px）：内容 2 行截断 + 单行 meta。 上下 padding 12/11，左右 14，圆角 8。列表间距 8，连续排列时呼吸均匀。 不使用渐变、玻璃拟态、重阴影；颜色只服务于状态（蓝选中 / 琥珀固定 / 红删除）。

Hover / 焦点

按钮绝对定位，不改变卡片高度，无布局跳动。鼠标移入按钮时仍保持卡片 hover（同卡片内）。 内容右侧预留 gutter，避免遮字。Tooltip 仅用于图标按钮。 Selected + Hover 同时保留光晕与操作区。

操作权重

复制（高频）在方案 B 才直出；固定可直出点亮态；删除不直出，仅菜单内红色项。 键盘可完成复制 / 固定 / 删除，与鼠标路径对等。

不放进默认卡片的信息

字数/字节、格式数量、重复标记、完整时间戳、标签编辑——放 Hover 提示、菜单或详情面板。 信息进卡片的唯一标准：是否帮助「扫一眼就认出这条」。
