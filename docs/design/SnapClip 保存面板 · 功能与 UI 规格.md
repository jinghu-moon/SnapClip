# SnapClip 保存面板 · 功能与 UI 规格

依据原型 `save-panel-demo-v3.html`（920 × 569 dip）整理 · 目标栈 Windows + Rust + Direct2D · 2026-10-18

## 0. 阅读指南

本文把原型里“看得见、点得到”的行为翻译成可实现的规格，并指出原型与真实实现之间的差距。

| 标记 | 含义 |
| --- | --- |
| 【原型】 | 原型已实现、可直接照做的行为与数值 |
| 【建议】 | 原型没有，但真实实现应当补上 |
| 【待决】 | 需要产品或设计拍板，汇总见第 15 节 |

原型里有几处只是演示替身，真实实现要换掉：浏览器 localStorage → 本地设置文件；canvas 编码 → 真实编码器；假的“已存在文件 / 已知目录”集合 → 真实文件系统检查；navigator.clipboard → Win32 剪贴板；DownloadURL 拖出 → OLE 拖放；预览里示意有损的模糊滤镜 → 真实解码后的编码结果。

章节顺序：1 定位 → 2 总览 → 3 状态 → 4 预览区 → 5 表单 → 6 浮层 → 7 底栏与保存 → 8 校验 → 9 长截图 → 10 键盘与无障碍 → 11 动效与 Token → 12 编码管线 → 13 依赖选型 → 14 D2D 实现要点 → 15 待决事项 → 16 验收清单。

## 1. 定位与设计原则

保存面板是截图确认之后的“输出站”：在写出文件之前，让人看清最终产物长什么样、有多大，并一步完成保存、复制或拖走。

| 原则 | 具体体现 |
| --- | --- |
| 所见即所存 | 右半预览就是编码后的真实结果，体积是实测值；对比滑块让画质损失一眼可见 |
| 默认即正确 | 命名模板、序号、体积上限、快捷路径、高级选项、保存后动作都被记住；什么都不动，按 Enter 就能存 |
| 问题就地说 | 路径、文件名的错误贴在字段标题行右侧，附一键修复；底栏同步显示首个错误 |
| 不打断 | 高级项收进浮层；越界、同名、目录不存在都是提示而非弹窗；保存后用 Toast，可撤销 |
| 动效只解释变化 | 数值滚动、行位移、切割线画出，都是为了让人看懂“什么变了”；系统开启“减少动画”时全部关闭 |

## 2. 面板总览

### 2.1 外观

深色半透明面板（rgba(23,23,28,.92)），12 dip 圆角，1 dip 内描边（白 30%），大范围柔和阴影；原型用 6 px 背景模糊示意毛玻璃。除输入框外文字不可选中。【原型】

### 2.2 区域与尺寸

| 区域 | 位置与尺寸 | 内容 |
| --- | --- | --- |
| 标题栏 | 高 44，左右内边距 16 | 标题“保存图片”（12 dip，600 字重）；右侧 26 × 26 关闭按钮（等同取消） |
| 左栏 · 预览 | 宽 556，列总高 460：模式栏 24 → 间距 8 → 画布（约 556 × 400）→ 间距 8 → 页脚 | 第 4 节 |
| 栏间距 | 12 | — |
| 右栏 · 表单 | 宽 320（920 − 2 × 16 − 556 − 12）；行间距 12，组间距 16 | 第 5 节 |
| 底栏 | 上方 1 dip 分隔线，上下内边距 12，按钮高 32 | 状态行、同名切换、复制 / 取消 / 保存 |
| 浮层 | 面板内绝对定位，高于内容层 | 格式菜单、命名变量菜单、高级选项、长截图 |
| Toast | 宽 340 | 7.6 |

右栏分三组，自上而下：

1. 保存路径 → 文件名 + 格式 → 保存后
2. 尺寸 → 质量
3. 预估大小

### 2.3 生命周期

- 打开：面板从下方 10 dip 处上浮并从 97.5% 放大，淡入 280 ms；预览自动“适应窗口”。【原型】
- 关闭：右上角 ✕、取消按钮、Esc（无浮层打开时）。保存成功后面板保持打开，用 Toast 反馈；保存后可继续调整并再次保存（D6）。
- 入口（工具栏按钮或快捷键）原型未涉及【待决】
- 高度：顶栏标注 920 × 569 dip，但按样式推算最小高度为 577（标题 44 + 内边距 16 + 预览列 460 + 底栏 57），右栏内容更高时（开启限制体积、JPG 填充行、长截图）还会增加；原型靠行位移动画平滑过渡。真实窗口是固定高度还是随内容缩放【待决】

## 3. 状态模型

### 3.1 状态字段

| 字段 | 默认值 | 含义 | 持久化 |
| --- | --- | --- | --- |
| 命名模板 | `SnapClip_[日期]` | 文件名模板，保存时才解析变量 | 持久 |
| 序号 | 1 | `[序号]` 的下一个值；含该变量的保存成功后 +1，撤销时 −1 | 持久 |
| 保存路径 | 桌面 | 目标目录 | 会话；【建议】持久为“上次路径” |
| 格式 | PNG | PNG / JPG / WebP | 会话；【建议】持久 |
| 质量档 | 高 | 高 / 中 / 低；PNG 与无损 WebP 无档位 | 会话；【建议】持久 |
| 输出尺寸 / 原始尺寸 | 等于原图 | 输出像素宽高 / 截图原始宽高 | 临时（每次截图重置） |
| 锁定比例 / 比例值 | 开 / 原图宽高比 | 解锁后再锁定时，比例取当时的宽高比 | 临时 |
| 尺寸模式 | 数值 | 数值（px）/ 百分比 | 会话 |
| 限制体积 | 关 / 500 KB | 开关与上限 | 持久 |
| JPG 填充色 | #FFFFFF | JPG 透明区域底色 | 会话；【建议】持久 |
| 同名处理 | 自动重命名 | 仅存在同名文件时有意义，冲突消失即复位 | 临时 |
| 高级选项 | 见 6.2 | 每种格式一组 | 持久 |
| 长截图分割 | 不分割 / 4 张 / 每张 2400 px / 多张图片 | 分割方式、张数、每张高度、输出形态 | 临时 |
| 预览视图 | 适应窗口 | 缩放与平移 | 临时 |
| 对比位置 | 50% | 0 = 全部编码后，100% = 全部原图；另记住最近一次中间位置 | 临时 |
| 预览背景 | 深色棋盘 | 四选一 | 会话；【建议】持久 |
| 快捷路径 | 桌面 / 图片 / 下载 | 至多 8 项 | 持久 |
| 保存后动作 | 复制路径 关 / 打开文件夹 关 | 各自独立 | 持久 |

### 3.2 派生量

| 名称 | 规则 |
| --- | --- |
| 是否长截图 | 输出高 ≥ 3000 且 高 / 宽 ≥ 2.5 |
| 输出为 PDF | 是长截图，且选了“单个 PDF” |
| 多文件输出 | 分割后张数 > 1，且不是 PDF |
| 无质量档位 | PNG（无论是否量化），或 WebP 开启无损 |
| 无损输出 | PNG 且未开色板量化，或 WebP 开启无损 |
| 实际质量档 | 无档位时恒为“高”；否则开启限制体积时取“满足上限的最高档”（都不满足取最低档），未开启时取手选档 |
| 目标路径 | 目录 + 解析后的文件名 + 扩展名；同名且处理方式为重命名时，取 `名_2`、`名_3`… 中第一个不存在的 |
| 阻塞 | 模板为空、路径为空、宽或高 < 1，或任一 error 级校验命中 |

## 4. 左侧预览区

### 4.1 模式栏

位于画布正上方，高 24，三段排布：原图居左 / 对比居中 / 编码后居右——位置对应分割线语义（左半原图、右半编码后）。左右两个按钮同时充当体积标签。

| 按钮 | 文案 | 点击 |
| --- | --- | --- |
| 原图 | `原图 · {体积}`，体积 = 原始尺寸无损 PNG 的大小，作为对比基线 | 分割线移到最右，全显原图 |
| 对比 | `对比` | 回到最近一次的中间位置（默认 50%） |
| 编码后 | `编码后 · [无损 · ]{体积} · [±N%]`，N% 为相对原图体积的变化，为 0 时省略 | 分割线移到最左，全显编码后 |

激活态为蓝底白字、500 字重，随分割线位置联动：到最右亮“原图”，到最左亮“编码后”，其余亮“对比”。悬停浅灰底，按下缩放 0.96，文字过长以省略号截断。

### 4.2 预览画布

- 背景四选一（见 4.6），圆角 10，1 dip 内描边。
- 图像居中；打开和尺寸变化后自动“适应窗口”：缩放 = min(画布宽 / 图宽, 画布高 / 图高) × 0.94，允许范围 5% – 800%。
- 原型里图像的圆角和窗口外框是示例图自带的；真实截图按原样显示，不额外裁圆角。【建议】
- 滚轮：以指针位置为锚点缩放，按滚轮增量的指数换算（系数 0.0015），可连续平滑缩放。
- 拖动：按住左键平移，光标 grab → grabbing；指针悬停画布时按住空格再拖也是平移（此时分割线不可抓，避免误碰）。
- 双击空白处：平滑回到“适应窗口”。
- 缩放过渡 260 ms（ease-out cubic），位置、像素网格、尺寸标签同步；滚轮缩放会立刻打断过渡。
- 缩放浮条在画布右下（距边 12，高 26）：`−`、百分比（等宽数字，点击 = 100%）、`+`、分隔、“适应窗口”图标。`+` / `−` 每次 ×1.25 / ÷1.25，以画布中心为锚点。拖动画布时浮条不拦截指针。

### 4.3 对比滑块

- 左半原图、右半编码后，两层互补裁切，接缝处多留 1 px 重叠防止露缝。
- 分割线：2 dip 白线 + 1 dip 深色外描边，可抓取热区 14 dip（光标 ew-resize）；悬停与拖动时变 accent 蓝。
- 握把：30 dip 圆形（surface 底、1 dip 描边、“‹ ›”图标），垂直居中；水平位置夹在 \[15, 画布宽 − 15\] 内以免出框；悬停、聚焦、拖动时描边变 1.5 dip accent，拖动时放大到 1.08。
- 拖动保留按下点与线的偏移（不跳变）；拖动中无过渡；点模式按钮切换时有 180 ms 位置过渡。
- 吸附：距边缘不足 1.2% 时吸到 0 或 100%。
- 双击分割线或握把：回到 50%。
- 键盘：握把聚焦时 ← / → 移 2%，Shift 移 10%，Home = 0，End = 100%；焦点不在输入框时 ← / → 同样控制分割线。握把对外是 0 – 100 的 slider。

### 4.4 有损效果的呈现

右半必须显示当前 artifact 解码后的真实结果；禁止用模糊或降对比伪造有损效果。PNG 无损时应与源像素一致；JPG 时透明区域显示为所选填充色。

【建议】真实实现不要用模糊示意：右半必须显示“编码后再解码”的真实像素（JPEG 块效应、WebP 涂抹、PNG 量化色带），这才是对比滑块的价值。参数变化后旧结果先保留，新结果就绪再淡入替换，避免闪烁。

### 4.5 像素网格与尺寸标签

- 缩放 ≥ 400% 时叠加像素网格：每个图像像素一格，1 dip 白线（22% 不透明），以“差值”混合，深浅背景下都可见。
- 尺寸标签：图像左下方 6 dip 处的胶囊（高 20，等宽数字，`宽 × 高`），显示的是输出尺寸而非原始尺寸；被画布边缘挤出时夹回（距边 ≥ 8 dip），随缩放与平移跟随。

### 4.6 预览背景

页脚左侧 4 个 16 dip 方块：深色棋盘（默认）/ 浅色棋盘 / 纯白 / 纯黑。选中项有 accent 描边环（1.5 dip 间隙 + 1.5 dip 环），悬停描边提亮；棋盘格每格 16 dip。用途：检查透明区域和边缘。

### 4.7 页脚

左：`原始 {宽} × {高}`（缩放比例只在缩放浮条里出现一次）、分隔线、背景切换。右：长截图按钮，仅长截图出现（第 9 节）。

### 4.8 拖出图片

画布左上（距边 10）的胶囊“⋮⋮ 拖出图片”（高 24），提示“拖到桌面、文件夹或聊天窗口，直接得到这张图”。

- 拖出的是当前设置下编码后的图，文件名 = 解析后的模板名 + 扩展名；不写入保存路径，结束后状态行提示“已拖出（未写入保存路径）”。
- 多文件分割或 PDF 输出时不可用：胶囊 35% 不透明、光标 not-allowed，尝试拖动提示“分割 / PDF 输出不能直接拖出”。
- 编码未完成时拖动，提示“正在编码，稍候再拖”。【建议】真实实现改为按需立即编码或写临时文件，不让人等。
- 拖动中胶囊缩到 0.94 并半透明，拖影为宽 120 的缩略图。

### 4.9 预览快捷键

| 键 | 作用 |
| --- | --- |
| 滚轮 | 以指针为锚点缩放 |
| + / = | 放大 ×1.25 |
| − / \_ | 缩小 ÷1.25 |
| 0 | 适应窗口 |
| 1 | 100% |
| ← / → | 移动分割线（Shift 步长更大） |
| 空格 + 拖动 | 平移（仅指针在画布上时） |
| 双击画布 | 适应窗口；双击分割线 = 回到 50% |

以上快捷键在焦点位于输入框、或按住 Ctrl / Alt 时不生效。

## 5. 右侧表单

### 5.1 保存路径

- 标题行：`保存路径`；右侧留给字段消息（第 8 节），如“⚠ 目录不存在，保存时创建 \[立即创建\]”。
- 输入行：路径文本框（等宽 12 dip，高 32）+ `更改`（打开系统文件夹选择器）+ 文件夹图标按钮（在资源管理器中打开当前路径；路径为空时禁用）。
- 快捷路径芯片（高 24 的胶囊）：默认 桌面 / 图片 / 下载。点击即填入路径；当前路径等于某芯片时该芯片高亮（蓝）。悬停显示完整路径，名称最长 96 dip 后省略。悬停芯片时右上出现 × 可移除；末尾的 `+` 把当前路径加入（名称取路径最后一段），路径为空、已存在或已满 8 个时禁用并说明原因。
- 【建议】默认芯片取系统已知文件夹（含 OneDrive 重定向后的桌面 / 图片 / 下载），不要写死用户名；芯片指向的目录已不存在（如外接盘拔出）时显示为灰态。

### 5.2 文件名与格式

- 文件名框保存的是“模板”，如 `SnapClip_[日期]`，变量在保存时才替换；框内右侧的魔法棒按钮用来插入变量。格式按钮在其右侧（宽 80，显示 `.PNG` 等宽字 + 下拉箭头，展开时描边变蓝、箭头翻转）。
- 命名变量（魔法棒菜单，宽 184，每项右侧显示当前值）：

| 变量 | 含义 | 示例 |
| --- | --- | --- |
| `[日期]` | 当天日期 YYYY-MM-DD | 2026-10-18 |
| `[时间]` | 当前时分 HHmm | 1432 |
| `[序号]` | 下一个序号 | 7 |
| `[分辨率]` | 输出宽 x 高 | 1440x900 |
| `[软件名]` | 应用名 | SnapClip |

- 点击变量：在光标处插入（有选区则替换），光标落在变量之后，输入框保持焦点。
- 序号：模板含 `[序号]` 时，每次保存成功后 +1 并记住；撤销保存时回退。模板与序号随输入实时记住。
- 扩展名自动追加（PDF 输出时为 `.pdf`），用户无需输入。
- 格式菜单（宽 156）：`.PNG` / `.JPG` / `.WebP`，每项右侧显示“当前尺寸与质量下的预估体积”，当前项左侧打勾；体积先模型估算，实测后覆盖。
- 切换格式会连带：质量行、高级选项内容、JPG 填充行随之变化，预估重新编码。
- 【待决】`[时间]` 只到分钟，同一分钟多次保存靠“同名自动重命名”区分；是否提供秒级变量。

### 5.3 保存后

一行：标签“保存后” + 两个可点选芯片（选中 = 蓝色填充）：

- 复制路径：保存成功时把完整文件路径放进剪贴板；失败时 Toast 提示“路径复制失败”。
- 打开文件夹：保存成功后自动在资源管理器中定位到该文件。

两者默认关、各自记住。“复制”按钮只复制图片，与此无关；手动打开文件夹已由路径行图标和 Toast 的“打开文件夹”覆盖。

### 5.4 尺寸

- 标题行：`尺寸`；右侧“数值 / 百分比”分段控件 + 重置图标（尺寸等于原始时禁用，30% 不透明）。
- 宽高行：`宽 [ 1440 px ]  🔗  高 [ 900 px ]`。输入框高 32，16 dip 等宽 500 字重数字，右对齐，单位为 px 或 %。
  - 百分比模式显示相对原始尺寸的百分比（取整），输入后换算为像素。
  - 中间的链环按钮切换“锁定比例”：锁定时改一边，另一边四舍五入联动；比例取锁定那一刻的宽高比；重置时回到原图比例。
  - 只接受正整数；↑ / ↓ ±1，Shift 为 ±10；聚焦自动全选；输入时不打断光标；被联动的一侧数字用 240 ms 滚动到新值，并闪一下蓝色描边（300 ms）。
  - 越界：任一边超过原始分辨率，该格描边与数字变橙，行下提示“超过原始分辨率，放大将损失清晰度”。
- 预设胶囊：100% / 75% / 50% / 25%，相对原始尺寸，常驻（两种模式下都在，切换不跳动）；当前尺寸恰等于某预设时该胶囊高亮。
- 任何尺寸变化：预览自动适应窗口，预估体积重算并重新实测。
- 【建议】限制输出的最大边长与总像素（例如单边 ≤ 16384，与 GPU 纹理上限一致）；原型只做越界提示，输入 99999 会拖垮内存。

### 5.5 质量与体积

- 标题行：`质量` · 高级选项按钮（调节图标，22 dip；当前格式的高级项偏离默认时右上角出现蓝点）· 右侧“限制体积”开关。
- 质量档：高 / 中 / 低 三段（宽 108，高亮块 140 ms 平移）。PNG 与无损 WebP 没有档位，改显示灰色说明：“PNG 格式是无损压缩，不支持质量调整” / “PNG 色板量化 · 有损，但没有质量档位” / “WebP 无损模式不支持质量调整”。
- 限制体积（开关状态持久）：打开后，质量档的位置换成 `不超过 [ 500 ] KB`。
  - 自动选“满足上限的最高质量档”，都不满足则用最低档。
  - 下方状态行：✓ 已自动选择“中”质量 · 312 KB；PNG 无损时为 ✓ 当前 312 KB，未超出上限；超限时橙色 ⚠ 最低质量仍为 640 KB，超出上限（PNG 为“⚠ 无损输出，当前 640 KB，超出上限”），并出现 `自动缩小尺寸` 链接。
  - `自动缩小尺寸`：把宽高等比缩小并重新编码，直到最终 artifact 文件长度不超过上限；不得用估算余量代替最终验证，随后宽高滚动并闪烁。
  - 上限输入：整数 KB，↑ / ↓ ±50，Shift ±200，下限 10。
  - 手动点选质量档 = 退出自动模式（开关随之关闭）。
- JPG 透明填充：仅 JPG 出现一行“透明区域填充” + 白 / 黑 / 自定义（彩虹圆点，点开取色器）；说明“JPG 不支持透明，透明区域会被填充为所选颜色”；预览右半实时反映。

### 5.6 预估大小

- 数值 `227.31 KB` / `1.20 MB`（等宽 12），变化时 320 ms 数字滚动。
- 标题行右侧状态：编码中为 `编码中 2/6`，标题行下方出现 2 dip 进度条，数值同时呼吸（不透明度 0.4 ↔ 0.85，周期 1 s）；完成后 `✓ 实测`（蓝色，320 ms 带回弹弹出）。
- 语义：先显示模型估算，后台实测完成后换成真实值（第 12 节）。

## 6. 浮层

### 6.1 通用规则

- 同一时刻只开一个浮层（格式 / 变量 / 高级 / 长截图互斥）。
- 点浮层外部关闭；Esc 先关浮层，再按一次才取消对话框；变量菜单点击不抢走输入框焦点。
- 开：160 ms 从触发点方向滑出并淡入（位移 ≤ 6，缩放 0.97）；关：110 ms，更快。
- 定位：贴着触发按钮，水平方向夹在面板内（边距 6）；格式菜单下方空间不足时向上翻；长截图菜单固定向上展开。
- 外观：圆角 10，内边距 5，surface 底、1 dip 描边、双层阴影；菜单项高 30–32、圆角 6。

### 6.2 高级选项（宽 264，标题 `{格式} 高级选项`）

| 格式 | 选项 | 默认 | 说明 |
| --- | --- | --- | --- |
| PNG | 压缩等级：最快 / 平衡 / 最小 | 平衡 | 越小越慢 |
| PNG | 色板量化 | 关 | 256 色，有损；UI 截图常省 50–70% |
| JPG | 色度采样：4:4:4 / 4:2:0 | **4:4:4** | 4:2:0 体积更小，但文字更糊 |

改动即时生效并持久化；“恢复默认”重置全部高级选项。体积始终来自真实 artifact 文件长度，不使用估算系数修正。WebP 固定无损且没有质量档位；不提供 WebP 无损开关、JPG 渐进式或移除元数据选项（D1–D3）。

## 7. 底栏与保存流程

### 7.1 布局

左：状态行（弹性宽度，超长省略，悬停显示完整目标路径）。右：\[`改为覆盖` / `改为重命名` 链接，仅同名时出现\] · 复制（幽灵按钮，带图标）· 竖分隔 · 取消 · 保存（主按钮，横向内边距 24，600 字重）。

### 7.2 状态行

自上而下取第一个命中项：

| 条件 | 文案 | 颜色 |
| --- | --- | --- |
| 存在 error 级校验 | 首个错误文案（无具体文案时为“名称或路径有误”） | 红 |
| 多文件输出 | 将生成 4 张 · 1440 × 2400（末张 …）· 名称\_1…4.png | 灰 |
| 同名且处理 = 重命名 | ⚠ 同名文件已存在，将保存为 {新文件名} | 橙 |
| 同名且处理 = 覆盖 | ⚠ 将覆盖已有文件 {文件名} | 橙 |
| 其他 | 完整目标路径 | 灰 |

瞬时反馈 2 s 后恢复：✓ 图片已复制到剪贴板、✓ 已在资源管理器中打开：{路径}、✓ 已创建目录、✓ 已拖出（未写入保存路径）等，成功为蓝、失败为红。状态文字变化时 200 ms 轻轻上浮换入（连续输入时 400 ms 内不重复触发）。

### 7.3 同名冲突

- 检测：目标目录下是否已有同名文件（不区分大小写），仅单文件输出检测。
- 默认“自动重命名”：保存为 `名_2`、`名_3`…（取第一个不存在的）；底栏出现链接 `改为覆盖`，点击在两种处理间切换（文字随之变为 `改为重命名`）。冲突消失时处理方式复位为重命名。
- 【建议】多文件分割输出的 `_1…n` 也要做冲突检测；覆盖前先把原文件移入回收站，撤销才能恢复（见第 15 节）。

### 7.4 按钮

| 按钮 | 行为 | 快捷键 | 禁用条件 |
| --- | --- | --- | --- |
| 保存 | 见 7.5 | Enter（焦点不在按钮 / 滑块 / Toast / 浮层上时） | 阻塞 |
| 复制 | 把当前设置下的图片放进剪贴板，状态行提示；不写文件、不改序号 | Ctrl+C（焦点不在输入框且无选中文字） | 原型随阻塞禁用；【建议】只依赖尺寸有效，与路径、文件名校验解耦 |
| 取消 / ✕ | 关闭面板，不保存 | Esc（无浮层时） | 无 |

保存按钮：悬停时内描边提亮，按下缩放 0.96；成功时一圈蓝色涟漪扩散（620 ms）。

### 7.5 保存流程

1. 计算目标路径（含冲突处理）与输出集合（单图 / 多张 / PDF）。
2. 目录不存在则创建（原型：保存即创建）。
3. 编码并写盘。【建议】直接写已缓存的编码字节，先写临时文件再原子重命名；失败给出明确原因，不关闭面板。
4. 含 `[序号]` 则序号 +1 并持久化。
5. 执行保存后动作：先复制路径，再打开文件夹。
6. 按钮涟漪、弹出 Toast、刷新状态行。
7. 【建议】写入历史记录，支撑 Toast 的“在历史中查看”。

### 7.6 保存后 Toast

面板存在时位于面板内底栏上方，距底栏 16 dip、右对齐，宽度不超过 420 dip；面板已关闭时位于屏幕工作区右下，距边 24 dip。两种位置均不得遮挡预览右下角尺寸标签（D7）。圆角 12、毛玻璃：左侧 48 × 32 缩略图，右侧标题 + 副标题，× 关闭；下方一行操作按钮；底部 2 dip 倒计时条（7 s，悬停暂停）。弹入 300 ms 带轻回弹，退出 160 ms 下沉淡出。

| 场景 | 标题 |
| --- | --- |
| 单文件新建 | 已保存 · {文件名} |
| 同名被改名 | 已保存为 {新文件名} |
| 覆盖 | 已覆盖保存 |
| 多张 | 已保存 {n} 张 |
| PDF | 已保存 PDF · {n} 页 |

副标题：有保存后动作时为动作结果（`路径已复制 · 已打开文件夹`，失败为 `路径复制失败`），否则为 `{目录} · {体积} · {宽}×{高}`。操作按钮：撤销 / 重命名（多文件无）/ 在历史中查看 / 打开文件夹。

- 撤销：删除刚写入的文件，本次递增过的序号回退，Toast 变为“已撤销”并说明“文件已删除：{名}”（2.8 s）；只对最近一次保存有效。
- 重命名：副标题原地变成输入框（预填不含扩展名的文件名并全选），倒计时暂停；Enter 确认（非法字符换成 `_`，留空则保留原名），Esc 取消并关闭 Toast；成功后标题变为“已重命名为 {名}”，操作按钮保留。

## 8. 校验规则

### 8.1 呈现

错误 / 警告显示在对应字段标题行右侧（10 dip：⚠ + 文案 + 可选修复按钮，上浮淡入）；输入框描边变红（error，刚进入错误态时横向轻抖 280 ms）或橙（warn）。任一 error → 保存与复制禁用，底栏显示首个错误；warn 不阻塞。

### 8.2 路径

| 级别 | 条件 | 文案 | 修复 |
| --- | --- | --- | --- |
| error | 为空 | 路径为空 | — |
| error | 不是完整路径（需盘符或 UNC 开头） | 请输入完整路径，如 C:\\Users\\… | — |
| error | 盘符之后含非法字符（尖括号、引号、竖线、问号、星号） | 路径含非法字符 | — |
| error | 无写入权限 | 没有写入权限，请换一个目录 | — |
| error | 磁盘空间不足 | {盘}: 仅剩 x，保存需约 y | — |
| warn | 目录不存在 | 目录不存在，保存时创建 | 立即创建 |

原型里“无写入权限”只是对 C:\\Windows、Program Files 的示意，“磁盘空间不足”只是对 E: 盘（假设仅剩 1 MB）的示意；真实实现用实际写入探测和磁盘剩余空间查询。

### 8.3 文件名

对“模板”检查非法字符，对“解析后的名字”检查保留名。

| 级别 | 条件 | 文案 | 修复 |
| --- | --- | --- | --- |
| error | 模板为空 | 文件名不能为空 | — |
| error | 含非法字符（尖括号、冒号、引号、斜杠、反斜杠、竖线、问号、星号）或控制字符 | 含非法字符 {去重后的字符列表} | 替换为 \_ |
| error | 解析后是保留名 CON / PRN / AUX / NUL / COM1–9 / LPT1–9 | “{名}”是系统保留名 | — |
| error | 完整路径超过 259 字符 | 完整路径超过 260 字符 | — |
| warn | 末尾是点或空格 | 末尾的点或空格会被系统去掉 | 去掉 |

方括号 `[ ]` 是模板变量，不算非法字符。【建议】真实实现用 Win32 API 做路径规范化、长路径开关与卷信息检查，而不是只靠字符串规则；多文件的 `_1…n` 后缀也要计入长度。

## 9. 长截图

### 9.1 触发与入口

输出高 ≥ 3000 且 高 / 宽 ≥ 2.5 时，预览页脚右侧出现胶囊 `✂ 长截图 · {摘要}`（摘要：不分割 / N 张 / PDF · N 页）；点击向上展开宽 280 的浮层，标题 `长截图 · {宽} × {高}`。尺寸改动后不再满足条件时，胶囊消失，分割设置不再生效。

### 9.2 浮层内容

| 行 | 控件 | 规则 |
| --- | --- | --- |
| 分割方式 | 不分割 / 按张数 / 按高度 | 三段选择 |
| 分成 | 数字输入（按张数时出现） | 2–20 张；每张高 = ⌊总高 / N⌋，余数并入末张 |
| 每张最高 | 数字输入（按高度时出现） | ≥ 200 px；张数 = ⌈总高 / 每张高⌉，末张较矮 |
| 输出 | 多张图片 / 单个 PDF | 两段选择 |
| 底部说明 | 实时文案 | 共 N 张 · 每张 W × H（末张 h）／ PDF 共 N 页，每页 W × H ／ 整张输出为一个文件 |

### 9.3 预览与保存

- 预览画布上画出虚线切割线（1.5 dip，蓝色小字色）与每段左上的编号胶囊 `i/n`（等宽 10 dip）；切割变化时线从左向右画出（380 ms），编号弹出（300 ms，带回弹）；跟随缩放与平移。
- 多张输出：文件名 `{名}_1…n.{扩展名}`，一次写出，Toast 为“已保存 n 张”，没有“重命名”按钮；状态行显示张数、尺寸与命名；拖出图片不可用；预估大小仍显示整图体积。
- PDF 输出：每个切片一页，扩展名 `.pdf`，Toast 为“已保存 PDF · n 页”；分割方式为“不分割”时是单页长 PDF。
- PDF：A4 纵向、边距 0；图像按页宽缩放并按页高分页，保持纵横比。1 px = 1 pt 仅在单页可容纳时成立；JPG 源可嵌入 JPEG，PNG 源使用 Flate，WebP 源一律转为 PNG/Flate（D10）。

## 11. 动效与设计 Token

### 11.1 动效规范

原则：出现比消失慢；位移 ≤ 8 dip（面板 10）；只做位移、缩放、不透明度；系统关闭动画时全部关闭。缓动：ease-out `cubic-bezier(.22,.61,.36,1)`；spring `cubic-bezier(.34,1.45,.64,1)`，仅用于“确认类”反馈。

| 动效 | 时长 | 说明 |
| --- | --- | --- |
| 面板出现 | 280 ms | 上浮 10 + 缩放 0.975 → 1，淡入 |
| 浮层打开 / 关闭 | 160 / 110 ms | 从触发点方向滑出；关闭更快 |
| 悬停 / 按下 | 140 / 100 ms | 背景、描边、颜色渐变；按下缩放 0.96 |
| 分段高亮块 | 140 ms | 质量档高亮块平移 |
| 对比位置过渡 | 180 ms | 仅点模式按钮时；拖动无过渡 |
| 缩放 / 平移 | 260 ms | ease-out cubic，可被滚轮打断 |
| 预估体积数字 | 320 ms | 数字滚动 |
| 宽高联动数字 | 240 ms | 输入中不打断；另闪描边 300 ms |
| 行位移 | 240 ms | 行出现或消失时，其下各行平滑位移 |
| 按需区块出现 | 200 ms | 淡入 + 自上方 4 dip 落下（限制体积行、填充行、字段消息） |
| 状态文字换入 | 200 ms | 上浮 4 dip；连续输入时 400 ms 内不重复 |
| 输入错误 | 280 ms | 横向轻抖 ±3 dip，仅在进入错误态时 |
| 实测完成 ✓ | 320 ms | 缩放 0.7 → 1，spring |
| 保存涟漪 | 620 ms | 按钮外扩 11 dip 的蓝色光环 |
| Toast 进 / 出 | 300 / 160 ms | 上浮 12 + spring；退出下沉 10 并淡出 |
| 切割线 | 380 ms | 从左向右画出；编号 300 ms spring |
| 编码呼吸 | 1 s 循环 | 预估数字不透明度 0.4 ↔ 0.85 |

## 12. 编码管线与体积估算

### 12.1 两级体积

编码完成前显示“准备中”；完成后以文件型 artifact 的实际长度显示体积。原型中的字节/像素系数只作 demo 占位，不用于保存、限制体积或缓存。

### 12.2 调度

1. 只在签名变化时重新调度：源身份、输出尺寸、格式、质量、PNG/JPG 高级项。
2. 180 ms 防抖，期间状态显示“编码中”。
3. 队列顺序：当前格式当前质量 → 同格式其余质量 → 原图 PNG 基线 → 其他格式（各档），保证格式菜单里每一项都有实测值。
4. 后台逐项编码；首个结果出来立即刷新界面。
5. 代际取消：参数再变，旧任务在下一项之前退出。
6. 超大图（> 250 万像素）缩小到约 250 万像素编码，再按面积外推体积。
7. 结果按（格式、质量、宽、高、无损标志、JPG 填充色）缓存，命中即跳过。
8. 完成后标 ✓ 实测；artifact 文件供预览、复制、拖出、保存共同使用。

### 12.3 质量映射

JPG 当前只承诺已实测的 Q92；Q75/Q50 在 D8 完成三类语料验证前不得作为产品档位。质量参数的文件体积不作为普遍单调不变量。限制体积必须以实际 artifact 长度验收；有限档位时逐个编码并选择实际满足上限的最高档，均不满足时再缩小尺寸并重新实测。任何搜索策略都必须对最终 artifact 做体积确认。

### 12.4 高级项的修正系数（仅原型）

| 选项 | 原型系数 |
| --- | --- |
| PNG 压缩等级 最快 / 平衡 / 最小 | ×1.06 / ×1.00 / ×0.94 |
| PNG 色板量化 | ×0.38 |
| JPG 色度采样 4:4:4 | ×1.18 |

真实编码器会直接应用这些选项，系数作废；编码缓存的键必须包含全部高级选项，否则改选项后会读到旧结果。

### 12.5 预览即编码结果

链路：捕获源 → 按目标尺寸缩放 →（JPG：合成到填充色）→ 编码为文件型 artifact。这份 artifact 同时用于：① 文件长度即实测体积；② 解码后作为右半预览；③ 保存与拖出；④ 复制时从 artifact 解码并发布剪贴板表示。不得为复制单独从源图生成另一份输出，因此剪贴板画面与预览、保存、拖出一致，包括有损编码的实际结果。剪贴板始终可发布从 artifact 解码得到的 `CF_DIBV5`；仅当 artifact 本身是 PNG 时，才可同时发布其原始字节为注册 PNG 格式。长图 artifact 落临时文件；解码与预览缓存须有按字节计量的上限。

## 13. 依赖选型

### 13.1 选型原则

- 性能：有 SIMD、能在后台线程跑、能中途取消。
- 质量：同体积下画质最好；无损路径必须真无损。
- 轻量：依赖树浅、feature 少、二进制增量小、编译快。
- 许可证：优先 MIT / Apache-2.0；GPL 类只在项目本身开源且兼容时考虑。
- 能用 Windows 自带能力的不引第三方（剪贴板、拖放、文件对话框、文字排版）。
- 纯 Rust 优先但不迷信：关键编码器（WebP）用静态链接的 C 库换成熟度与速度。

### 13.2 推荐总表

说明列末尾的标注：【已查证】= 本次联网核对过；【经验】= 工程经验判断，落地前需实机验证。

| 能力 | 推荐 | 备选 / 不推荐 | 说明 |
| --- | --- | --- | --- |
| 系统 API | `windows`（windows-rs，当前 0.62.x），只开用到的 feature：Direct2D、DirectWrite、DXGI、DirectComposition、Shell、OLE、Ime、DataExchange、Storage\_FileSystem | 不用 winapi（已不再活跃维护）；不引 winit | 官方绑定；COM 接口可用 `#[implement]` 自己实现（拖放需要）。【已查证版本；其余经验】 |
| 缩放（输出尺寸） | `fast_image_resize` 6.x | `image` / `resize` 自带缩放 | SSE4.1 / AVX2 / Neon 加速；支持 Lanczos3、Bicubic、Box、Bilinear；支持 4 通道 8 位像素与预乘 alpha；官方基准里 AVX2 下把约 500 万像素 RGB 图缩到 852 × 567 的 Lanczos3 只要十几毫秒量级。它缩放时不做线性光转换，截图缩放一般不需要。【已查证】 |
| PNG 编码 | `png`（image-rs）+ `flate2` 的 `zlib-rs` 后端 | 别把 Fast 模式当默认；追求极限体积可选 `oxipng` 做后台“再压缩” | 纯 Rust、无 unsafe、有模糊测试。其 Fast 模式（fdeflate）对照片极快，但第三方对比显示在 UI 截图与图表上体积明显偏大（约 +130%），而“自适应滤波 + 默认压缩”对文字类截图最强。建议映射：最快 = Fast + Sub；平衡 = Default + 自适应滤波；最小 = Best + 自适应滤波。【已查证（第三方基准，需自测）】 |
| PNG 色板量化 | `quantette`（Wu / k-means，带抖动，MIT 或 Apache-2.0） | `imagequant` 观感公认最好，但许可是 GPL-3.0+（闭源需商业授权）；zenquant 为 AGPL，不建议 | 第三方对比中 k-means 模式的逐像素指标领先，imagequant 的主观观感最好。其 `threads` feature 依赖 rayon，要极致轻量就关掉自己并行。【已查证】 |
| JPEG 编码 | `zenjpeg`（项目现有实现） | `jpeg-encoder` / `mozjpeg` 需重新评估 | 当前采用 baseline 行带写出与项目已有画质、正确性测试；D2 删除渐进式，不为未使用的扫描路径引入额外复杂度。若重新选型，必须保留 4:4:4 默认、4:2:0 高级项和真实 artifact 解码验收。 |
| WebP 编码 | `zenwebp`（项目现有实现，仅无损） | `libwebp-sys` 仅在未来重新开启有损 WebP 时评估；`image-webp` 作为解码/无损备选 | D1 已定只做无损，当前不引入有损库或质量档；实现必须遵守 WebP 尺寸、像素预算并在超限前拒绝。 |
| PDF（长截图单 PDF） | `pdf-writer`（Typst 团队，0.15，低层、禁用 unsafe） | printpdf、pdf\_oxide 等高层库 | 只需“每页一张图”：JPEG 以 DCTDecode 原样放入，无损用 FlateDecode；依赖最少。WebP 须先转 JPEG / PNG。【已查证库；JPEG 直通属 PDF 规范能力】 |
| 复制图片 | `windows` 直接调用：artifact 解码后提供 CF\_DIBV5；仅 PNG artifact 额外提供原始 PNG 格式 | arboard、clipboard-win | 不再引第三方；JPEG/WebP 字节不得标成 PNG，也不为剪贴板另行编码。【D9】 |
| 拖出图片 | OLE：`DoDragDrop` + 自实现 `IDropSource` / `IDataObject`，提供 CF\_HDROP（指向临时文件），结束后清理 | 虚拟文件（FILEDESCRIPTOR + FILECONTENTS）更省磁盘，但部分聊天软件不识别 | 原型的 DownloadURL 是浏览器机制，不能照搬。【经验，需在目标应用里实机验证】 |
| 选择文件夹 / 定位文件 | `IFileOpenDialog`（`FOS_PICKFOLDERS`）/ `SHOpenFolderAndSelectItems` | rfd 等跨平台对话框库 | 系统原生，零额外依赖。【经验】 |
| 文本输入 | **自绘 TextField：DirectWrite 排版 + IMM32 组合输入** | 原生 EDIT 子窗口（不采用） | 面板里 6 个输入框共用同一组件；需支持插入点、选区、拖选、双击选词、撤销、复制粘贴、键盘导航、IME 候选窗定位与 UIA。行为由组件和测试负责，不依赖原生控件。【D11 已定】 |
| 动画 | 自写 Tween（约 150 行：缓动曲线 + 目标值 + 时间轴） | Windows Animation Manager（COM，API 偏重） | 动效清单见 11.1，全是标量插值，用不上通用动画库。【经验】 |
| 设置持久化 | `serde` + `serde_json`（或 `toml`），写临时文件后原子替换 | — | 持久字段见 3.1；极致轻量可手写简单 ini。【经验】 |
| 并行与取消 | `std::thread` + `std::sync::mpsc`，原子“代际号”取消；长截图多切片并行用 `std::thread::scope` | `rayon`（偏重） | 编码任务少而重，标准库足够。【经验】 |
| 日期时间 | `windows` 的 `GetLocalTime` | `chrono` / `time` | 命名变量只要年月日时分（秒）。【经验】 |
| 不推荐 | `image` 全家桶、`opencv`、`skia-safe`、`cairo`、WebView | — | 体积与编译时间远超需要，且与原生 D2D 路线重复。 |

### 13.3 取舍与许可证

- feature 取舍：`windows` 只开用到的模块；`fast_image_resize` 不开 `image` 互操作；`quantette` 只开用到的量化方法；`jpeg-encoder` 开 `simd`；`flate2` 选 `zlib-rs` 后端。
- 许可证：以上推荐均属 MIT / Apache-2.0 体系（libwebp 为 BSD 类许可，静态链接时随附许可声明）。imagequant 是 GPL-3.0+ 与商业双许可、zenquant 是 AGPL，项目将来若闭源分发就不要引入。建立 THIRD\_PARTY 清单，并在发布流水线里用 cargo-deny 之类的工具检查。
- 版本：本文写作时核实到的版本为 windows 0.62.x、fast\_image\_resize 6.x、jpeg-encoder 0.7.x、pdf-writer 0.15、image-webp 0.2.x、zenwebp 0.3.x；其余以 crates.io 当前版本为准，并锁定 Cargo.lock。

### 13.4 选型验证方案

- 语料：三类截图（深色 IDE、文字密集网页、含照片的页面），各取 1080p 与 4K。
- 指标：编码耗时（含缩放）、体积、画质（目视 + SSIMULACRA2 之类的指标）、峰值内存、二进制体积增量、冷编译时间。
- 要回答的关键问题：① PNG：Fast 与 Default + 自适应在 UI 截图上的体积与耗时；② JPEG：4:2:0 与 4:4:4 对文字边缘的画质差；③ WebP：libwebp 与 zenwebp 的体积、速度、画质；④ 色板量化：quantette 与 imagequant 的观感差距；⑤ 缩放：Lanczos3 与 Bicubic 的速度与观感。
- 【建议】性能目标（待基准校准）：改参数后首个实测值在 1080p 上 ≤ 200 ms；4K 全部实测在后台 ≤ 1.5 s 且不卡 UI；缓存命中时点保存到文件落盘 < 50 ms。

- 对比滑块：拖动流畅无撕裂；吸附、双击回中、键盘微调、模式按钮联动都正确。
- 缩放平移：滚轮锚点准确；≥ 400% 出现像素网格；按住空格拖动期间分割线不可抓。
- 命名：5 个变量插入位置与值都正确；序号保存后 +1、撤销后 −1；模板重启后仍在。
- 尺寸：锁定比例联动、百分比换算、预设高亮、越界橙色提示、↑ / ↓ 步进。
- 格式与质量：PNG / 无损 WebP 隐藏质量档并显示说明；JPG 出现填充色；格式菜单显示各格式实测体积。
- 限制体积：自动选档文案正确；超限出现“自动缩小尺寸”并真能满足上限；手动点档退出自动。
- 高级选项：每种格式的选项真实影响输出；偏离默认时出现蓝点；恢复默认生效。
- 路径与文件名：8.2 / 8.3 每条规则都能触发并给出文案与修复；error 禁用保存。
- 同名冲突：默认 `_2` 命名；覆盖 / 重命名可切换；多文件整组检测。
- 保存：Enter 保存；序号与保存后动作（复制路径、打开文件夹）按序执行；Toast 文案与操作齐全；撤销与重命名可用。
- 复制与拖出：Ctrl+C 复制的图可直接粘贴到聊天或文档；拖到资源管理器与常见聊天软件得到正确文件名与内容。
- 长截图：判定阈值、按张数 / 按高度的分割数字、切割线预览、多文件命名、PDF 页数都正确。
- 键盘与 UIA：全程可只用键盘完成；讲述人能读出控件名称、状态与错误。
- 动效：全部符合 11.1；系统关闭动画时无动效。
- 性能：空闲 CPU ≈ 0；改参数时界面不卡；4K 图全部实测不阻塞主线程。
